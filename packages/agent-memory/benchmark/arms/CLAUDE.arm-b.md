
## Project notes

Keep `NOTES.md` at the project root up to date. It is this project's memory
between sessions:

- decisions, with their reasons;
- approaches tried or considered and dropped, and why;
- the current task, its state, and what's left;
- open problems and what they're waiting on.

Read it at the start of every session, and update it before you finish.
Check what's current with `git log`, `git diff` and grep rather than
trusting the notes alone.
